# gis-website

Greenfield herbouw van de Get Inspired Society website.

Dit project is volledig losstaand van [`getinspiredmedia/on-view`](https://github.com/getinspiredmedia/on-view). Er zijn geen gedeelde dependencies, databases of configuraties.

## Starten

```bash
npm install
npm start
```

## Paden

| Pad | Pagina |
|---|---|
| `/` | Home |
| `/on-view` | On View |
| `/magazine` | Magazine |
| `/gallery` | Gallery |
| `/society` | Society |
| `/about` | About |
| `/contact` | Contact |
| `/support` | Support |

## Deployment

Gedeployed via Railway. Auto-deploy op push naar `master`.
